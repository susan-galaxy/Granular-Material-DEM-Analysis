# 气液相变数据分析系统 (Maxwell_Boltz)

本项是对颗粒/活性物质在微重力环境下的颗粒物质及速度关联函数的分析工具集。

## 🌟 核心功能
* **混合编程优化**：底层采用 C++ 进行高频碰撞数据处理，通过 pybind11 为前端 Python 提供高效接口。
* **统计物理建模**：实现了高精度的速度分布拟合与取向序参量（Orientational Order Parameter）计算。
* **自动化可视化**：一键生成符合 Nature/PRL 期刊标准的矢量图表。

## 🛠️ 技术栈
* **Languages**: C++, Python, MATLAB
* **Tools**: Git, CMake, pybind11
